## Peach 采用与差异

- **「不画底色、边框和磨砂层」这一条不采用**。2026-09-05 用户当场指定：这三颗与右下角
  「稍后看」同款，只是尺寸大一号，要有背景和框。用户的界面决定优先于这份截图证据，
  这里只记录取舍，不据截图回推。
- `.hovertools.seektools button` 只覆盖图标尺寸（34px）。底色、边框、磨砂和悬停填充全部
  由 `.hovertools button` 共用规则给出，命中区域仍是 58px 圆。58／34 与「稍后看」的
  36／21 是同一个比例，一排控件因此读成一组。
- 秒数由 `title` 与 `aria-label` 承担（「后退 10 秒」），DOM 里没有数字角标。秒数本身仍
  可在设置里改。
- 图标用本地 Lucide 的 `rotate-ccw`／`rotate-cw`，不复制 beeg 的 SVG 路径。
- 同组第三颗「打开详情」沿用同一外观，一排三颗不混两种写法。
- 右下角「稍后看」按钮的磨砂圆底不变——它是持久状态而不是瞬时控件，`aria-pressed`
  的开态需要一块面来承载。
