# Folia 播放墙取证与 Peach 适配

本文件是人工取证与实现判断，不登记到 `docs/reference-sources.json`：人工笔记不能被线上原文覆盖。原文登记为 `folia-wall-blocks` 和 `folia-wall-style`，保存在 [矩形块模板](upstream/folia-block-templates.ts) 与 [墙面样式](upstream/folia-wall.css)。

## 证据

2026-10-13 用 `gh api` 取得 `chthollyphile/folia-major` revision `9a01e788ed52d25ea01b1f0d37934e5e371ae82b`，许可证 AGPL-3.0。源码实测：`PosterWall.tsx` 使用 DOM 世界层变换，`layout.ts` 只生成视口附近实例，`LatticePoster.tsx` 单击先展开、独立控件播放；`BravaisCollection.tsx` 的探索层循环，筛选层使用有限拼贴。`blockTemplates.ts` 的块为 12×8 单位、12 个槽位；拖动阈值为 7 px，惯性与滚轮处理可被输入打断。

官网是文档入口。浏览器两次返回 `js execution timed out; kernel reset`，实时交互未取得；用户截图只用于聚焦卡与背景层级的参考，不作为动效尺寸实测。

样式源码实测：暗色背景 `#070707`、文字 `#f7f4ee`，封面标题 `clamp(22px, 2vw, 36px)`、字距 `-0.045em`，悬停 `saturate(1.08) brightness(1.05)`，展开阴影 `0 42px 110px`、透明度 74%。`PosterWall.tsx` 的单元为 128、间隙为 8，桌面缩放 0.76；由此推导墙面步长为 103.36。直角拼贴、角落控制、背景暗化及中央方形展开区按源码和用户截图重建。展开封面铺满卡片，视频按原比例居中显示，后方封面使用模糊。

展开跨度为 6×6 单位；推导桌面展开边长为 `(6 × (128 + 8) - 8) × 0.76 = 614.08 px`。Peach 在同一磁贴内展开，复用上游四套模板、镜像及让位表；手机和低视口通过相机缩放保留完整展开卡。

动效源码实测：`wallReflowMotion.ts` 的展开与收起共用 `stiffness:300`、`damping:34` 弹簧；同块十一张磁贴同时换位。控件从下方 12 px 淡入，延后 140 ms、持续 240 ms。`useWallCameraPan.ts` 居中飞行持续 420 ms，曲线 `[0.22,1,0.36,1]`。Peach 使用已有 Motion 布局投影与世界层变换，保留拖动打断和 reduced motion。原文登记为 `folia-wall-reflows`、`folia-wall-motion`。

把展开卡单独放在中央会丢失原位展开及块内让位的关系，不符合用户要求，已改为同一磁贴展开。 <!-- copy-lint-disable-line -->

用户明确要求 Folia 的独立页面形态；馆藏内嵌的网格切换不符合该要求，已撤销该入口。 <!-- copy-lint-disable-line -->

## Peach 行为

右上角常驻入口进入独立 `/wall` 页面，馆藏顶栏、侧栏和筛选条收起；左上角返回来处，旁边的圆形换批键复用首页图标和等待动效。右下角工具提供搜索、封面／缩略图和缩放。馆藏与实体作品入口继承当前搜索、筛选及作品范围；其他页面进入普通馆藏范围并保留返回地址。探索墙按视口实例键分配作品，四向移动时自动补充未出现的封面，无封面页继续跳过，全部耗尽后循环；已看位置和镜头在续页及详情返回时保持。手动换批期间墙面灰化并模糊，数据就绪后展示新区域。搜索、标签、状态、时长及实体作品墙每个条目只展示一次，用「载入更多」续页。固定三列保证有限墙已有位置不变。

初版探索墙只循环当前批次，四向拖动未接续馆藏，造成作品频繁重复；2026-10-14 按用户反馈改为按需分配与自动分页。 <!-- copy-lint-disable-line -->

高亮效果来自已登记 `folia-wall.css` 的 `.lattice-poster.is-current::before`：2px 描边、52% 黑色内侧细线、46% 亮色的 15px 内侧发光；聚焦使用 26px、62% 发光。Peach 使用中性亮色，选中与播放均高亮，其余磁贴叠加暗层。作品队列滚轮交给 `MixQueue` 滚动区，不移动墙面镜头。

墙面先挂载，取数期间使用相同拼贴几何的骨架。HTML 首帧标记 `/wall` 入口，模块等待期隐藏目录；初始化跳过首页骨架，React 接管时清理入口标记。无结果和请求失败仍保留返回与工具入口；清空搜索可继续浏览，失败可原地重试。

播放墙支持四向拖动、触控板、Shift + 滚轮横移、方向键、缩放与回到起点。只有带实际封面引用的视频进入墙，缩略图模式不改变资格。封面复用 `ArtSlot`、`cardArtwork`、`coverAnchor` 和缓存：宽磁贴使用全封，窄磁贴使用正封，跟随人脸锚点；正封框保留完整高度。展开封面使用全封并铺满卡片，墙内图片容器使用直角裁剪。标题叠在中下部，番号按实际字宽缩小到一行完整显示，作品标题单行截断；点击播放后缩小移到左上方，视频后面的封面模糊，关闭键有圆形黑底。墙内隐藏播放器的统计与速度浮层。

镜头和选中实例按集合保存，分页由共享 Query 在刷新代次之间认领，进出详情保留当前批次及已载入范围。展开的实例在视口外仍保持挂载，移动镜头不会卸下播放器；收起可交给小窗，详情认领同一实例。墙和普通卡片共用 `openCardDetails`。墙内直接读取共用分卷／版本队列，选择后在原卡片播放；支持上一部、下一部、暂停、进度和同版本下一卷续播。控制条只监听共用 video，流源与统计仍由共用播放器处理。计费、在线及脱盘作品由详情规则处理。独立表面固定使用 Folia 暗色样式，保留 Peach 的身份和操作语义。

## 验收与影响面

验收入口为 `scripts/test.ps1`／`scripts/test.sh`。`wall-layout.test.ts` 验证重复、去重、负坐标、裁剪、边界和续页位置；`stage-player.test.ts` 验证墙面、小窗、详情的实例交接、来源门槛和取消；`video-wall.test.ts` 验证桌面及 390×844 手机拖动、图片切换、全屏、详情返回、实际演示短片播放，并输出首次布局截图。

- 数据层：不改变 schema、查询或身份；播放统计及稍后看沿用已有动作，测试使用临时账本或请求桩。
- API：沿用 `/api/items`、`/api/item`、`/api/parts`、`/api/editions`、来源状态与播放接口；`/wall` 登记 GET／HEAD 单页入口，无新增数据契约。
- 页面：馆藏和实体作品区的顶栏进入独立页面，详情及小窗共用播放器；关注、沉浸、统计、标签索引、复核、Mix 与回收站不新增播放墙。
- 反向状态：进入／返回、工具展开／收起、作品展开／收起、稍后看／移出均可返回。
- 视口：桌面和手机分别验证溢出、长标题及操作状态。
- 文档：同步中英文 README、复用、参考登记和运行事实；不增加规则或 ADR。
- 生产：以本轮集成后实际重启及严格 HTTPS 健康核验为准。
