# 任务进度与容器清单

此清单依据用户截图整理，没有可重抓的上游文档 URL，因此不登记到 `docs/reference-sources.json`。

按用户于 2026-09-29 提供的口味、扫描与链接管理截图复核。后台任务有确定总量时显示进度条；未知总量时显示 Loading Dots，同一位置只显示一次状态文字。

独立状态块使用描边卡片；已有任务卡、设置分组或结果面板的状态使用所在容器，不叠加第二层框。两种主题共用语义边框和背景 token。`TaskProgress` 负责这两种容器，`Progress` 只负责数值图形。

| 页面或位置 | 状态 | 容器 |
| --- | --- | --- |
| 口味 | 读取、分析浏览记录；导入文件 | 独立描边块，主按钮与下拉半边同步忙态 |
| 数据管理：扫描与采集 | 扫描、资料采集 | 扫描任务卡正文，按钮在分隔底栏 |
| 数据管理：媒体修复 | 修复文件 | 媒体修复任务卡正文 |
| 数据管理：整理 | 生成预览、执行整理 | 整理任务卡正文，不叠加状态框 |
| 数据管理：链接管理 | 检查链接、重验并删除 | 站外链接任务卡正文，主按钮在分隔底栏；结果表使用结果面板 |
| 数据管理：资源同步 | 核对文件、复核与清理 | 文件与记录核对任务卡正文 |
| 关注管理：关注列表 | 检查更新、抓取历史 | 关注列表卡正文 |
| 关注管理：添加关注 | 解析链接、按名称查找 | 添加关注卡正文；输入建议的等待点位于建议菜单 |
| 活动 | 每项正在运行的任务 | 活动任务卡正文 |
| 来源和凭证 | 抓取封面、重建运行环境 | 设置分组正文 |
| 配置：更新与维护 | 下载、校验、解压、准备安装 | 更新设置分组，保留阶段刻度 |
| 目录顶部 | 扫描与采集全局提示 | 紧凑通知栏，使用环形进度 |
| 遗留任务状态（`jobs.ts`） | `jobActivityHtml` 的调用方 | 沿用所在操作区，使用环形进度或等待点 |

统计页的覆盖率、容量、观看比例，口味页的覆盖率，以及媒体卡片的观看进度，表达的是数据比例，不是后台任务，不增加任务状态框。索引页「载入更多」按钮内的等待点也不是独立任务面板。

统计页骨架按四张读数卡、两张环形图和三张分布图排版；重复页骨架按汇总、玻璃批量操作条、组头和文件行排版。加载占位与正文使用相同响应式列数和容器宽度。回收站网格与管理标题、汇总栏共享 `--board-content`；垃圾文件页不显示订阅新作，晚到的目录请求也不能重新插入该区域。
