## Peach 采用与差异

用户原话：「不用照抄，因为我们宽度不一致，窄屏下可以参考，你来自己发挥一下」。

- 窄屏一栏，人名行照截图的形态：40px 圆形头像、名字、一行「N 个视频 · 事务所」。
- 宽屏按下拉栏自己的宽度分栏（容器查询，≥720px 两栏）：左栏是身份和词，右栏是视频封面格。
  一栏宽到 420px 时人名行右侧摆四部近作的小封面，点封面直接开详情。
- 截图里右侧那个计数挪进副行，右侧位置留给近作封面。
- 页签多一枚「全部」，各类页签带这段输入在该类的命中总数，用 Board 的计数徽标
  （`.ui-board-tab-count`）；样式照复核分类那排药丸：选中只有填充，未选中悬停只提字色。
- 视频、女优、创作者、厂牌、事务所、系列、标签各是一类，只列有命中的那几类；
  只有一类命中时不出页签。
- 点人、公司和系列进资料页，点标签照旧按词搜索，点视频开详情。
- 尺寸取自 Peach 自己的写法：公司标识 28px 圆片（与厂牌药丸同形），小封面沿用卡片的
  3:4 容器与正封取景。
