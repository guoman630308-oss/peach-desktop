# JavDB 类别译名与身份复核

用户确认具体译名可新增规范标签，各职业、偏好、身体部位和行为分开表达，不以泛化标签代替。译名自然，同义词统一；复合类别保留原义，含义未取得时保留原文。

## 规范含义

- 「风俗女郎」是作品角色，「风俗店」是场景；女优资料中的 `風俗嬢` 使用资料专用词表「风俗从业」，不由作品角色推断真人经历。
- 「恋腿」「恋乳」是偏好，「美腿」「美乳」「巨乳」是外观；「扶她」是幻想设定，与「跨性别」分开。
- 靴子不必有高跟，湿身不必来自汗水，饮尿不同于放尿；母亲角色不自动推出母子关系或近亲剧情。
- 婆婆是配偶的母亲，继母是父亲的妻子；女主播、播音员、女搜查官与女检察官各有不同职业范围。`婆婆`、`女主播`、`女檢察官` 的中英文冲突不按英语单方面定去向，保留原文待复核。
- `口爆/吞精` 不同时断言两个行为；`車站性交`、`觸摸打字`、`養尊處優` 等异常词继续复核，类别名称本身不足以确定作品内容。
- `無碼流出`、`無碼破解` 等来源版本词保存在来源快照，不据此给本地文件标无码、AI 去码或泄密剧情。发行、营销、排名和兜底类别同样不生成内容标签。

规范词表位于 `catalog_rules`，来源映射位于 `genre_taxonomy`，复核选择、筛选和统计复用现有消费者，无新增依赖或账本迁移。真实馆藏回填按 ADR-0100 的逐资产预览、同轮授权与备份要求执行。
