## 可复用证据

在 1124×911 的桌面视口中，页面按以下阅读顺序排列，文档宽度 1109px，没有横向溢出：

1. 160px 圆形头像与名称、计数组成资料头。
2. 简介紧随资料头，正文最大宽度约 430px。
3. 外部链接使用 36px 高的横向胶囊按钮。
4. 关联艺人使用圆形头像加下方名称的横向滚动带。
5. 主题与标签使用可横向延伸的胶囊行。
6. 内容列表排在上述资料和筛选信息之后。

SweetieFox 主 JS 提供了更明确的媒体切换证据：

- `IndexInner` 把媒体切换作为 `ContentFilter` 的 `prepend-chips`，因此它位于标签／推荐胶囊左侧，不另起 Tab 行。
- 页面只渲染一枚 `PicsIcon`。默认视频视图未选中；照片视图选中同一按钮，再次点击删除 `media=photos` 并返回视频。
- 按钮使用 `IconButton size="s"`：32×32px、圆形、默认透明，选中时使用实底；标签行间距为 6px。
- `PicsIcon` 是 16×16、`fill="currentColor"` 的三段路径，锁定于主 JS module `83646`。Peach 复用这份图形，不用原来的四宫格代替。
- 内置浏览器读取 SweetieFox DOM 和截图分别在 30 秒、15 秒超时并重置控制连接；实时计算样式与截图标记为“未取得”，没有据此补动画或其他数值。当前 HTML／JS／CSS 经代理下载成功，以上行为可由锁定 bundle 重放。

## Peach 复用与差异

- 女优、厂牌资料页采用“头像与名称 → 简介 → 链接 → 艺人轨道 → 标签与媒体切换 → 内容”的顺序；艺人轨道和标签行不显示重复标题。
- 有照片时，在标签左侧显示同一枚图片按钮；按钮的按下态表示当前是照片视图，点击可在视频／照片间往返。没有照片时不显示按钮。
- 关注页复用相同的信息层级：“标题 → 作者 → 状态、来源和标签 → 视频／图片 → 内容”。
- Reislin 页面只显示视频；SweetieFox bundle 证明只有 `tg_photo_sets` 时才插入媒体按钮。Peach 同样由真实照片数量决定是否显示，不伪造入口。
- Peach 保留自己的暗色变量、实体筛选、计数和操作语义，不复制 Beeg 品牌、关注按钮或外部商业链接。
- 合集的适配方式按 Peach 详情页截图定下：普通详情仍是左媒体、右信息，合集／Mix／分卷／播放列表／多媒体切换改为下方横向轨道，不使用原来的右侧竖向队列。
