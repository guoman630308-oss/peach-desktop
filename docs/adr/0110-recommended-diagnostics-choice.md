# ADR-0110：技术诊断共用推荐选项

- 状态：已采纳
- 日期：2026-10-18
- 相关：ADR-0109、ADR-0023

## 决策

版本与平台统计、自动错误诊断共用「发送版本统计与错误诊断（推荐）」开关，安装与首次设置默认勾选，用户可取消或在设置页关闭。服务端要求两类事件共同开启或关闭；本机没有选择记录时默认开启，保存的关闭选择持续生效，损坏或仅开启一项的记录均不发送。首次设置请求省略诊断选项时沿用本机选择。

安装辅助进程只在本机取证，不发送版本统计或错误诊断，避免安装预检早于最终选择保存时上传。应用进程按本机选择发送，后台队列发送前复查选择版本，关闭使待发送事件失效。字段白名单、同类错误去重与每日限额沿用[远程诊断说明](../DIAGNOSTICS.md#可选远程诊断)。

馆藏与口味群体研究独立默认关闭。完整字段预览、主动勾选同意、字段版本、独立项目及每周限额均按 ADR-0109 执行。

本决策修订 ADR-0109 中技术诊断的选择与默认值。回归使用临时数据根与 SDK 内存接收端，验证默认开启、取消与持久关闭、损坏记录、队列失效和安装辅助进程禁止上传；没有真实 ledger 写入。
