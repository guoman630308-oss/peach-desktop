# ADR-0112：明确同意的完整馆藏与口味明细

- 状态：已采纳
- 日期：2026-10-18
- 相关：ADR-0109、ADR-0110

## 决策

群体研究保留作品编号、标签、人物、创作者、厂牌、系列、媒体类型、时长、评分、喜欢状态和观看汇总，以及七类偏好的名称、强度和证据来源类别。所有维度使用现有口味模型，不随机化或删减成分类统计。字段版本为 `3`，授权须明确对应本契约。

研究默认关闭，与技术诊断共用「数据上传」分区，开关独立且始终可见。设置页列明全部字段、生成本机预览，并要求主动确认同意。同意后收起字段、预览和同意框，保留预览入口。安装器提供默认不勾选的独立明细上传项；主动选择后显示完整字段与接收说明页，继续表示同意，返回可取消选择。辅助进程只保存选择。静默安装保留已有选择。

不发送账号、设备或安装标识、内部行号、文件名、路径、标题、媒体、网址、搜索词或逐条浏览与观看时间线。完整明细仍可能跨次关联或与外部信息匹配，Sentry 会接触连接 IP；去标识不构成匿名或不可关联保证。本契约接受该边界；界面中的「匿名处理」仅指移除直接标识，完整明细的字段和关联能力不因此改变。见 [NIST IR 8053](https://csrc.nist.gov/Pubs/ir/8053/Final)。

## 传输与代价

快照使用独立 Sentry 项目的内存 gzip 附件，每 UTC 自然周最多尝试一份。gzip 无损保留所有 JSON 字段，原始 JSON 上限 100 MiB、压缩附件上限 18 MiB；超过任一上限则整份拒绝，不上传截断片段。Sentry 文档给出的请求上限为压缩后 20 MB，附件上限为每事件解压后 100 MB，客户端保留请求开销余量；SDK 后台发送前复查授权版本、字段和附件大小。详见[诊断核验](../DIAGNOSTICS.md#馆藏与口味群体研究)。

预览与后台采集不写真实 ledger、偏好缓存或浏览偏好缓存。大预览在页面显示前 24,000 个字符，并提供完整本机 JSON 下载。完整预览与 gzip 附件保留敏感偏好，下载文件应由使用者管理。关闭停止后续发送，已经接收的数据无法经本机开关撤回。
