# ADR-0113：面向群体分析的馆藏投影

- 状态：已采纳
- 日期：2026-10-19
- 相关：ADR-0109、ADR-0112

## 决策

研究以群体的作品收藏覆盖、评分分布、明确反馈和人物等偏好为目标。字段契约为 `4`，授权须明确对应此契约。

逐作品列表仅保留规范编号与实际存在的用户信号。同编号副本合并，无编号条目只参与本机分组汇总。出演者、创作者、厂牌、系列、手动标签、年代和时长以收藏、喜欢、不喜欢、观看及评分分布表达；有编号作品与无编号条目分开计数，主动收藏的实体单独标记。技术标签、自动刮削标签、逐作品完整元数据和浏览行为推断不属于投影。详细字段与去重规则见 [DIAGNOSTICS.md](../DIAGNOSTICS.md#馆藏与口味群体研究)。

独立默认关闭、完整字段与本机预览、明确同意、独立 Sentry 项目、每周上限、传输白名单和 gzip 边界继续适用。改变字段版本使既有同意失效，用户可查看投影后重新选择。作品组合与评分仍可能关联，去除直接标识不保证匿名。

投影只读 ledger，不读取浏览历史或写入缓存。群体统计须区分作品持有与主动喜欢、已评分与未评分、有编号与无编号，以及每周累计快照与新增事件。接收端分析是独立消费过程；Sentry 附件接收本身不生成业务聚合看板。
