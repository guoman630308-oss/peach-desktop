# ADR-0111：私有上下文与账本导出保存在仓库外

- 状态：已接受
- 日期：2026-10-18
- 修订：ADR-0015 的记录分层、ADR-0073／0075／0106 的种子分发位置

## 决策

公开仓库保留通用产品说明、运行方式、契约、来源证据、复用知识和架构取舍。个人交接、待办、运行状态、一次性审计、开发环境坐标、馆藏统计与真实媒体指纹保存在数据根的私有上下文中。公开文档不引用私有记录的具体文件名。

从账本导出的实体组合即使只包含公开字段，也可能反映个人馆藏。实体种子默认保存在 `<数据根>/state/seed/entities.json`，不随代码和发行包分发。导出、校验、显式导入与既有后继逻辑继续使用同一种格式；缺少私有种子包时不派发导入任务。

Git 忽略规则与仓库整洁检查拒收私有记录、数据库、运行产物及个人实体种子。测试使用临时账本与合成样本。已有记录先备份到仓库外，再从当前代码树移除；不改写真实账本或删除媒体。

## 边界

当前树删除文件不会抹除历史提交。历史清理涉及提交标识和远端引用重写，应单独确定范围；常规提交与推送不承担历史清理。
