# ADR-0077：隔天重传按作品专属的毫秒时长归组

- 状态：Accepted
- 日期：2026-09-26
- 修订：ADR-0058「后果」里保持分开的隔天重传

## 背景

Memz 在 rule34.xxx 上的 Grace Ashcroft 动画分成了两张卡：18148361 于 07-18 上传，
18193355 与 18193376 于 07-23 上传。三帖是同一段 60.054 秒的动画，连发判据接不住：

- 相隔 4 天多，超出 3 小时的连发窗口。
- 后两帖多挂了 `resident_evil_9:_requiem`，身份标签集合不同。

能拿来当证据的只剩时长。2026-09-26 在真实 ledger 上只读核对过另外两条路：

| 判据 | 结果 |
| --- | --- |
| 文件 MD5（`content_hash`） | 三帖各不相同，重传时重新编码过 |
| 缩略图画面签名 | 两对 dHash 相差 12 与 14、色块差 55 与 67：站上生成缩略图取了不同的帧 |

## 决策

`follow_store._align_reuploads` 排在连发判据之后，四个条件同时成立才把两帖的组合并：

1. 同一来源，时长到毫秒相同，而且这个时长在这个来源里只出现在一种角色组合上。整秒的
   时长不认。
2. 角色标签集合相同，作品标签不看。
3. 一般标签 Jaccard 重合度不低于 0.5，与连发判据同一个阈值。
4. 发布时间相隔 3 小时以上；同一时段里的几帖归连发判据管。

合并的是整组的键。有出处或共用 `group_hint` 的组只当锚，一次合并只能有一个锚。第 1 条的
固定导出长度按筛选前的全部条目认（`FollowStore.group` 的 `population`），不按当前这一页。

## 依据

只读试算，16649 条可见条目，11957 组：

| 判据 | 新并出的组 | 抽查 |
| --- | --- | --- |
| 同来源、同角色、同毫秒时长、重合 ≥ 0.5 | 60 | LazyProcrastinator 一小时内的 43 帖 Raven 串成一张卡 |
| 再要求相隔 3 小时以上 | 38 | 20.02、31.232、45.045 秒的组占一半，画面多数不同 |
| **再要求时长只属于一种角色组合（采用）** | 14 | 拼图逐组看过，Memz 在内；没有拆开任何旧组 |

固定导出长度的分布没有中间地带：被并组的时长在同一来源里要么出现在 55 到 98 种角色
组合上（LazyProcrastinator 的 20.02 秒是 29.97 帧率下的 600 帧），要么只有 1 到 3 种。

重合度阈值：缩略图完全一致的三对重传，重合度分别是 0.96、0.69、0.47；抽查到的同一来源
同时长的不同动画最高 0.40。

## 拒绝方案

- 按缩略图画面合并。重传的缩略图取帧不同，Memz 这对都判不出来。
- 按文件哈希合并。重传都重新编码；同一个哈希分在两张卡的 293 个文件里，大多是 pawchive
  每月帖子共用的同一张横幅图。
- 时长加容差。60.054 与 60.075 只差 0.021 秒，却是两位作者的两种导出长度。

## 后果

- 重合度 0.47 的那对（InitialA 的 7657264 与 7664287）仍然分开。
- 用固定导出长度的重传仍然分开：LazyProcrastinator 的 17799100 与 17809026 缩略图完全
  一致，时长是 20.02 秒。
- 两帖各写了不同出处的重传仍然分开，比如 Pantsushi3D 隔 392 天发的两条推。
- 作者只用一种角色组合时，他的固定导出长度也会被认成专属时长；同一角色隔几天的两部
  时长逐毫秒相同、标签又重合过半时会并到一起。
