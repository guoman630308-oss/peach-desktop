# ADR-0067：女优资料落 `performer_profile` 单表，avwikidb 只作编号与交叉核对

- 状态：Accepted
- 日期：2026-09-25

## 背景

minnano-av 的女优资料页是一张表：別名、生年月日、サイズ、血液型、出身地、所属事務所、
趣味・特技、AV出演期間、デビュー作品、ブログ、公式サイト、タグ。账本只用到其中两格：
別名进 `entity_alias`（ADR-0055），事务所进 `entity.metadata_json.agency`。其余都没存，
需要单独存储其余资料，才能按出生年份、身高或活动状态筛选。

avwikidb.com 另有一份女优库：女优页 `/actor/<编号>/` 带 JSON-LD `Person`（读音、罗马字、
身高、出生日期、DMM 小图），作品页 `/work/<番号>/` 的 JSON-LD `Movie` 列着出演女优与编号。
站内搜索是 Next.js 页面上的弹层，地址形态未取得。两站的图都是 125×125。

展示方式用户还没定，这一轮只做数据层与后继。

## 决策

**一、资料落单表，不进 `metadata_json`。** 新表 `performer_profile`（迁移 `0036`），一位一行，
`entity_id` 为主键。出生日期、身高三围、罩杯、血型、出身地、趣味特技、出道年、活动截止年、
出道作品与日期、博客与官网各占一列；站上标签一份 JSON，资料表原文一份 JSON。要按列筛、
按列排的量放进 JSON 只能整段取出来在 Python 里拆，列也没有类型。别名与事务所保持原来的去处，
这张表不重复存。

**二、解析不到就是 NULL，不猜。** 日期要年月日三段齐全且合法才写 ISO；尺寸是厘米整数，
写成横线的是没填；`AV出演期間` 后半没写就是在役，`active_until` 为 NULL。规整规则只在
`minnano_av.profile` 一处，原文另存，规则改了可以就地重算。

**三、代码判据确定，直接落库（ADR-0052）。** 补女优资料后继 `performer-profile` 按 ADR-0053
派发：新登记的女优先派，存量每轮至多 16 条。minnano-av 的入口与补别名后继同一条（有编号直进，
没有按名字检索唯一命中），资料页的主名或別名栏里得有账本里她的名字才写；检索进来的顺手登记编号。
每行记批次号 `auto:performer-profile@<任务行 id>`，`revert_auto_landing.py` 按它连同登记的编号
整批撤回。`source` 不以 `auto:` 开头的一行是人写的，不覆盖。

**四、资料 30 天算旧。** 写成之后记号保 30 天，到期再派一次，资料页按取回时间过了 30 天才重取；
有一站「未取得」的记号只保 24 小时。

**五、avwikidb 只作编号来源与交叉核对。** 编号只从她自己作品的出演表里取：名字与账本里她的
某个名字折叠后相等，或罗马字与 minnano-av 上她的罗马字按词相等，恰好一位对得上才绑。对不上、
对上两位、没有非 FC2 作品，都写「未命中」，不按名字猜编号。编号已属另一条实体只记「占用」。
女优页的出生日期、身高与 `performer_profile` 不一致时，资料表不改，两边的值记进这条外部编号的
`metadata_json.conflicts`，后继摘要给条数。

**六、两站的图都不作头像。** minnano-av 的 `/p_actress_125_125/` 与 avwikidb 引用的 DMM
`actjpgs` 都是 125×125，低于头像门槛；地址只记在外部编号的 `metadata_json.image`，不下载。

**七、限流不绕。** 两站都按 3 秒间隔，与补别名后继共用同一个进程内限速器和 minnano-av 页面缓存；
avwikidb 登记为 `scraping_access` 的来源，走 `SourceTransport`，撞上 429、403 与机器人验证照
冷却记录停下。

## 后果

- 迁移 `0036` 应用之前，这条后继每一条都会因缺表失败；排单不读这张表，其余后继照常派。
- `merge_entity` 带上这张表：保留一侧已有资料就留它的，没有才接被并入那一侧的。
- 判词写进 `generated/performer-profile-landing.csv`。
- 界面暂不展示这些资料。

## 未决

- avwikidb 的站内搜索地址未取得。只有 FC2 作品或作品都不在站上的女优，这一站绑不上。
- avwikidb 女优编号与 DMM 女优编号看起来一致，未核实，不作判据。
