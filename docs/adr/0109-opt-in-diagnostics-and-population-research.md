# ADR-0109：明确同意的远程诊断与群体偏好研究

- 状态：已采纳；技术诊断的选择与默认值见 [ADR-0110](0110-recommended-diagnostics-choice.md)，馆藏明细契约见 [ADR-0112](0112-complete-library-sharing.md)
- 日期：2026-10-18
- 相关：ADR-0023、ADR-0092

## 决策

Peach 使用 Sentry 托管服务接收可选技术诊断。版本与平台统计、自动错误诊断均默认关闭，安装器、首次设置和设置页列明用途与发送字段，选择保存在本机。诊断复用现有错误取证入口，只投影异常链、代码位置、错误码和确定的媒体故障类别；预期失败与泛化噪声留在本机。完整日志与 ZIP 仍由用户主动导出。

馆藏与口味群体研究是独立默认关闭的功能，目标为自愿参与群体的作品、标签、评分和偏好分布。设置页展示字段与完整本机预览，用户主动勾选并同意才可开启。后台读取要求有效同意与独立接收项目同时存在；字段版本改变须重新同意。

研究发送同一 UTC 自然周内每机最多一份明细快照。作品编号合并文件副本，派生偏好复用当前模型，保留评分、累计播放与观看比例；不发送账号、设备标识、跨周期安装标识、文件名、路径、媒体或逐条浏览／观看时间线。明细存在再识别可能，不称为匿名数据；群体结论只能代表自愿样本，不能把安装或文件数量解释为独立用户数。

技术诊断与研究使用不同 Sentry 项目；两个传输只接受各自载荷，同意文件、限额与关停行为独立。研究使用内存 JSON 附件，不写快照队列或补传历史。两条通道发送前复查同意版本；关闭让排队记录失效，已经发送的信息不能通过本机开关撤回。真实数据收集须由每位用户在自己的部署中选择，本次开发验证只用临时数据。

## 实现与代价

复用固定版官方 `sentry-sdk` 的后台 HTTP、TLS、协议与服务端限流；不另建 Workers 接收、存储和问题查看后台。SDK 自动集成、追踪、会话、日志与指标采集关闭。本机额外保留授权版本、周期尝试与错误指纹；不写真实 ledger。具体字段、限额、接收端配置和验收见[日志与诊断核验](../DIAGNOSTICS.md)。

两项目在 Sentry 组织内仍共用套餐额度，普通统计事件与研究事件均占事件额度，研究附件另占附件额度。没有 DSN 时不会外发；Sentry 真实接收与群体分析看板须分别验收，客户端发送尝试不表示服务端已接收。
