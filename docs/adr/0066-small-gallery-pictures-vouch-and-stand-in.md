# ADR-0066：图库小图可以作证，也可以在最后一档装上

- 状态：Accepted
- 日期：2026-09-25
- 修订：ADR-0056「没过尺寸门槛的不比」、ADR-0062 第一条「过尺寸门槛的候选两两比」

## 背景

补头像后继把没过 `acceptable_avatar`（长边 500、短边 300）的图库候选在比对前直接跳过，
不取脸特征、不参与互证。缺少单人封面参照时，大图可能需要小图作第二份身份证据；全部候选都偏小时，也可能存在能确认身份但不能满足展示尺寸的图。

尺寸门槛管的是「装上去够不够清楚」，不是「这张是不是她」。认人时把小图扔掉，丢的是证据。

## 决策

**一、小图作证。** 图库比对里没过尺寸门槛的候选照样取脸特征、进 `compared`：在 ADR-0057 的三方
互证与 ADR-0062 的图库自证里可以当作证那张，也计入多数的分母；但不当被装上的那张。

**二、小图兜底。** 过门槛的图库候选与封面截脸两档都落空、盘上又没有别的头像时，装一张认得准的
小图：名下只有一张就装它；有好几张时照同一套判据挑，小图也能当胜者，认定的几张里挑像素最大的。
边车 `source_kind` 记 `gallery_small`，活动页来源写「（小图兜底）」。

**三、之后可换。** `gallery_small` 与封面截脸一样算可换的一档：有了过门槛的图库候选或封面人脸，
下一轮就换掉。人挑的、图库按门槛装上的不碰。

**四、判据版本。** `MATCH_RULE` 升到 4，存量里缺图的女优按新判据各重比一次。

## 后果

- 多数那一条的分母变大：名下的小图若是别人，原来两张大图互证过半的，现在可能不过半。这是有意的：
  那几张小图同样挂在这个名字下，只数大图等于替名字挑了证人。
- 小图兜底装上的头像在卡片上会糊一些，比首字母强；头像选择器里仍可一点换掉。
