# ADR-0058：连发帖挂到同批有出处的那组，连发与连号都看站内 id

- 状态：Accepted
- 日期：2026-09-24
- 修订：ADR-0046 决策（只处理无出处条目、身份只看作品与角色标签）、ADR-0045 决策第三条（id 间隔）

## 背景

关注页上有三处同一作者、同一天的卡片没合成一张，逐条查了 ledger：

| 样本 | 卡在哪一条 | 实际数值 |
| --- | --- | --- |
| InitialA 在 rule34.paheal 的 Lily Artemis II | 连发判据只收无出处帖；paheal 不给标签分类，身份集合为空 | 同批 9 帖，8 帖出处是 subscribestar 2685233，最后一帖没写，晚 25 秒 |
| LazyProcrastinator 在 rule34video 的 Barney's Mom | 连号间隔超过 30 | `Riding` 4608531 与下一条 4608595 相差 64；时长同为 20 秒 |
| Rekin3D 在 rule34.xxx 的两帖 | 身份多一个 `horseguy`；一帖有出处 | 站上上传是 05-01 与 05-20，id 相差 198043 |

第三个样本不是漏合并。两帖落库时间都是 09-14 03:0x，是 dapi 的 `change`（最后修改时间）：
09-14 有人一起改了这两帖的标签。上传时间取详情页 Posted 的修正（a6ff2138）之前落库、
已经补齐过分类的行不会再进第二阶段，`published_at` 就一直是改标签那一刻。

这也说明 ADR-0046 只看时间不够：一批旧帖被一起改标签，几个月前各自上传的帖子就成了
「几分钟内连发」。

## 决策

连发判据（`follow_store._align_tag_bursts`）：

1. 有出处或与别的条目共用 `group_hint` 的帖子参与判断，但只当锚，键不动。没出处的一串
   帖子前后 3 小时内、按同样的身份与重合度能对上的锚全在同一组时，这一串归进那一组；
   对上两组以上，只在这一串里互相归。
2. 这一步排到 `_align_by_group_hint` 之后，锚所在的那组已经共用一个键。
3. 相邻两帖的站内 id 相差不超过 3000，锚与帖之间同样。id 不是纯数字的站只看时间。
4. `tag_types` 里全是 general 的站（rule34.paheal）身份取整组标签（小写），整组相同才算。

连号判据（`follow_store._align_upload_packs`）：相邻两条的 id 间隔从 30 放到 100，其余
条件不变。

## 依据

2026-09-24 在真实 ledger 上只读试算，16019 条可见条目，分组数 11745：

| 判据 | 新并出的组 | 并入条目 | 拆开的旧组 | 抽查结论 |
| --- | --- | --- | --- | --- |
| 连发挂锚，只看时间 | 16 | 23 | 0 | 8 组 id 相差 2 万到 97 万；取得上传时间的 7 组全部相隔 4 天到 3 个月 |
| **连发挂锚，加 id 上限 3000（采用）** | 8 | 14 | 1 | 8 组都是同一批；拆开的那组 id 差 776581，站上 02-14 与 04-24 上传 |
| **再把连号间隔放到 100（采用）** | 再加 2 | 再加 2 | 0 | Barney's Mom 一包、Taka84 同一片的三个字幕版 |

最终分组数 11730，按来源：rule34.xxx 5 组、rule34.paheal 2 组、rule34video 2 组、
混合组 1 组（主条目在 pawchive）。逐组记录、缩略图地址与判断在主检出
`build/fgm-audit.csv`。

id 上限的取值：现有连发串的 349 对相邻帖里，347 对 id 差不超过 1000，一对 1383（3 分钟内
的同一批图），一对 776581（即上面拆开的那组）。rule34.xxx 实测约每天 1 万个新 id，3000 大致
是 7 小时，比 3 小时的时间窗宽，只拦改标签造成的假连发。

连号间隔的取值：除 id 外其他条件都满足的相邻对，id 差 44、48、64 的全在同一天；往上
第一对是 263，已经跨天（`Ashley (black, full ver.)` 与 `(white, full ver.)`），再往上的
`Lavinia-cowgirl` 与 `Lavinia-doggystyle` 相差 300、隔一天，是同一角色的两段新片。

## 拒绝方案

- 把改标签的时间修回上传时间再判。那要重新请求每条旧帖的详情页，是抓取侧的回填，
  不能靠读时判据完成；读时判据先用 id 挡住，回填另议。
- 锚对上两组以上时挂最近的那组。来源自己把它们分成了几个作品，挂哪组都是猜。
- 连号间隔放到 300 以上。隔天的同角色新片会并进来，用户定过隔几天的新作不并。

## 后果

同一批里没写出处的那一帖跟进有出处的那组，paheal 的连发也能认出来。仍然漏的是同一段
片子隔几天重传的情况（InitialA 的 11127566 与 11176396 时长逐毫秒相同，站上隔 6 天上传），
按隔天不并的边界保持分开。落库时间是 `change` 的旧行，卡片上的日期仍是改标签那天。
