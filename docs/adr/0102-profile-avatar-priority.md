# ADR-0102：清晰档案小图优先于封面裁片

- 状态：Accepted
- 日期：2026-10-11
- 修订：ADR-0066 的小图安装次序与替换规则

## 依据

用户确认 `深美みりあ` 的 Minnano 350×350 档案照可以接受，并要求优先于 204×204 的作品封面裁片。用户还指出同一图以“图库/来源”和“封面人脸/作品”各占一格的重复现象。本机核对见数据根 `review/fukami-avatar-audit.json`。

## 决策

自动选择依次尝试标准图库人像、短边至少 300 像素的档案小图、单人作品封面截脸与馆外互证封面，最后才是更小的图库兜底。300 像素复用标准头像的短边下限；不降低标准图库的长边门槛。

身份判据保持一致：唯一合格名字命中沿用名字核对，多张同名候选仍须封面或图库互证。小图选择复用 `match_gallery`，小图证人不受安装尺寸限制。手选头像和标准图库头像保留，自动封面裁片可以被合格档案小图替换；合格档案小图保留到有标准图库人像可用。`gallery_small` 继续记录来源类型，`MATCH_RULE=7` 让既有自动兜底记录按新判据复核。

候选列表仅按本机字节哈希和既有裁切函数的输出哈希去重：整图框选产生的重编副本、封面默认裁片与其历史项共用一格；不同裁切仍各占一格。在用状态保留，优先显示具体图库来源或作品番号；作品的封面与九宫格底图完整保留，与默认框完全一致的历史裁片可从同一框恢复，不重复增加底图入口。原图、历史缓存和人工选择不删除。

展示去重不参与自动身份判定，避免把同名的多来源记录压成“唯一候选”。列表不为去重请求外部图片，不引入感知哈希或新的识别模型。

## 影响面与验收

- 数据与契约：无 schema、ledger 真相字段或 API 字段修改；只调整头像后继与候选列表。
- 页面：共用换头像弹层接收去重列表，既有框选底图承载历史；无布局或样式修改。
- 反向状态：人工选择保留，相同裁片可按默认框恢复，不同历史图可重新框选；清晰小图可升级至标准图库人像。
- 回归：覆盖 350×350 优先、自动裁片替换、同名核验、手选保护、尺寸边界、整图重编去重、局部裁切保留及作品底图完整性。
- 运行核验、桌面与 390×844 视口证据保存在数据根 `review/avatar-profile-priority-verification/`。
- 复用：沿用 Pillow 裁切、尺寸校验、Gfriends 名字链与既有 SFace 身份核验，无新增依赖。身份与来源优先级属于 Peach 领域规则。
