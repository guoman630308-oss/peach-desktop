# ADR-0057：图库两张照片可以替一张封面参照作证

- 状态：Accepted
- 日期：2026-09-24
- 修订：ADR-0056 第二条（判据）

## 背景

ADR-0056 要求图库候选和两张封面参照都过 SFace 阈值 0.363，才算她本人。一张参照就能过，
等于一张认错人的封面就能让她装上别人的脸。

石川祐奈（实体 9107）按这条装不上。她的两张单人 FC2 封面截出的脸彼此余弦 0.005：
4159457 那张截到的不是她，和三张图库图各只有 0.008～0.070。另一张 3347918 和 Digigra、
Moodyz、DAS 三家的图各 0.548～0.606，三张图库图两两之间 0.591～0.663。规则因为一张截错的
参照，把清楚的正脸挡在外面，最后退到封面截脸，装上的是一张糊图（截图清晰度 12.8）。

## 决策

**一、互证。** 没有一张候选过够参照时，再找这样一对候选：

- 两张都和同一张参照过线；
- 两张彼此也过线；
- 两张彼此的余弦低于 `NEAR_DUPLICATE`（0.9），即它们不是同一张照片。

找到就认定是她，按图库先后装排在前面的那一张。一张封面加上两张不同的照片三方互相认得，
证据和「一张候选对上两张封面」同样多。两张候选都挂在她的名字链下，一张截错人的封面
要凑出这样一对，得图库里恰好有那个人的两张照片挂在她的名下。

**二、近重复不算两份。** 同一张照片在几个目录各存一份（缩放、重压、AI 放大）很常见，
只是一份证据。2026-09-24 实测：同一张图缩到一半或三分之一再放大、按 JPEG 80 重压，
SFace 给 0.942～0.974；石川祐奈三张不同照片两两 0.59～0.66。线取 0.9。

**三、仍要封面。** 没有单人封面参照时照旧不装：`ななみ` 这种单名命中的二十几张里，同一个
别人的两张照片也会彼此过线。无封面参照的图库互证见 ADR-0062。

**四、留证据。** 边车的 `face_match` 多一个 `corroborated_by`：作证那张候选的 `ref` 与
两张之间的分数。`required` 照旧记 2，`covers` 里只有一张过线，靠 `corroborated_by` 读出
这张是互证认定的。

## 后果

- 只读重跑 9107：装上 Digigra 那张，作证的是 Moodyz 或 DAS 中的一张。
- 参照只有一张时第一条用不上：那时一张参照过线就已经够了（ADR-0056 第二条）。
- 指纹多一段判据版本（`作品数:别名数:r2`，`MATCH_RULE`）。旧记号全部不再匹配，存量里缺图
  或装着封面截脸的女优按新判据各重比一次，包括 ADR-0056 估计里「比过但没有一张过线」的 19 位。
  以后再改认人判据，把 `MATCH_RULE` 加一即可。
