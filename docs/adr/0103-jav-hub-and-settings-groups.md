# ADR-0103：JAV 工作台与设置分类

- 状态：Accepted
- 日期：2026-10-11
- 关系：修订 [ADR-0050](0050-settings-modal-holds-values-pages-hold-work.md) 的设置分类与配置入口；JAV 订阅身份沿用 ADR-0047、ADR-0083。

## 决策

JAV 独立入口包含「我的馆藏」「发现」「想要」。馆藏复用现有 JAV 编目与搜索，使用目录的全宽网格、女优／厂牌／标签筛选、排序和版式工具；顶部搜索框负责馆藏搜索。发现从已采集的未入库新作读取真实资料，按口味记录中的出演者信号匹配。没有匹配时显示实际空状态，不生成作品或推荐理由。想要保存待找作品及其入库进度。

关注负责创作者和女优订阅、来源更新与新作。作品入库清单属于 JAV；来源凭据和采集参数属于服务配置。已有链接进入对应分区。

「查找资源」支持按番号搜索和粘贴已有磁力，先展示取得的作品资料，再展示资源候选，最终动作是「提交下载」。作品搜索与资源搜索分别操作；没有作品资料时不借用其他作品的封面或元数据。查询不要求先配置下载渠道，下载提交继续受渠道配置与账本写入权限约束。

设置弹窗保留，分为「外观与导航」「浏览与播放」「JAV 与新作」「搜索与推荐」「内容显示」。服务配置是独立导航入口，不属于偏好分类，也不在弹窗中重复挂表单。

服务配置分为「媒体库与入库」「来源与订阅」「下载渠道」「网络与访问」「应用与维护」。缩略图采集属于媒体库，首次采集范围、检查频率与头像刷新属于来源，资源索引器属于资源搜索。本机访问端口属于网络；媒体文件夹和端口保存使用同一配置修订号，分别提交时保留另一组已保存的值。

「来源与订阅」提供采集来源与登录状态入口，进入现有资料采集工作页管理来源连接、Cookie 与登录验证。该页的采集任务和高清封面操作继续在工作页完成。

## 文案与路径

字段名和按钮应直接说明用途。保留错误、权限限制、重启影响、配额与不可逆后果；连接帮助和凭据文件位置按需展开。页面不常驻内部实现、计算口径和重复解释。

脚本默认路径读取项目配置，个人目录偏好由参数明确指定。安装身份、协议端口与演示路径保留各自语义，不作为个人路径删除。

## 边界

本次不迁移账本、不新增推荐依赖、不自动下载作品，也不改动账号凭据。页面控件复用 BoardUI、现有设置接口与查询缓存；推荐范围受已采集的新作和已有记录限制。
