# ADR-0082：生词收录后按并集补标签，人批准标签只增不删，目录名窄兜底认番号

- 状态：Accepted
- 日期：2026-09-27
- 相关：ADR-0018、ADR-0038、ADR-0052、ADR-0079

## 背景

2026-09-27 复核页清完一轮之后，还有三类行按 ADR-0052「证据足的自动落」本该不用人看：

- **生词收录了，标签却没进账本。** ADR-0038 让标签部分落库，三张表都不认的词记进
  `note.pending_genres`。词收录之后复核页按 `genres_still_pending` 把这一行藏起来，可自动落库
  对带 `pending_genres` 的行一律不重判，收录出的标签只在页面上消失。整套重落也走不通：标签落过
  一次，现值就不空了，javbus 这类非官方来源不能改非空的现值（ADR-0033）。
- **人批准过的标签过期，候选比账本少。** 来源给出的标签集合可能减少或停用某个原词；重判不能删除人工批准的标签。
- **文件名读不出番号。** 文件名可能只写编号的数字段，直接父目录却写着完整番号；宽泛的目录名解析又可能把论坛合集误认成作品身份。

## 决策

**一、生词收录后按并集补收录出的标签。** 自动落库的批准（note 有 `auto_applied`）带
`pending_genres`、其中有词已经有了去向而还没补过时，用落库那条候选（按 `candidate_key` 或
`refreshed_candidate_key` 认，genre 按现在的决定折过）只插这几个词收录出的标签；落库后被手删的
其余标签不跟着回来。归属是 `auto:metadata-tags@<时间>`。note 的 `pending_genres` 原样留着，补过的
词记进 `collected_genres`，补进去的标签累加进 `added_tags`；词收成非内容时只记 `collected_genres`。

**二、人批准过的标签重判时只增不删。** 修订 ADR-0079 决策二的表格：

| 重判结果（按现在的词表换过名） | 原决定 | 做法 |
| --- | --- | --- |
| 候选全在账本里 | 人批准的 | 真相不写，只追加 `refreshed_candidate_key` |
| 候选有账本没有的标签 | 人批准的 | 只插那几个，人批准过的一个不删；追加 `refreshed_candidate_key` 与 `added_tags` |

账本里一个标签都没有、落库的闸不过（资产已删、来源番号对不上），仍交人。其余字段不变。

**三、文件名读不出番号时，按直接父目录窄兜底。** 下列条件全部成立才算这一组认得出番号：

1. 组里没有一个文件名 `_filename_carries_code`，也没有一个文件名 `release_code_from_filename`
   读得出任何番号——读得出别的番号时照旧交人；
2. 番号是明确形态（`is_jav_code`）；
3. 直接父目录名逐字（不分大小写）包含完整番号，目录名不跑番号解析；
4. 同一个文件的文件名里单独出现番号最长的那段数字，至少三位，并列时取最后一段。

撤回口径与 ADR-0079 决策四相同：`revert_auto_landing.py --source auto:metadata-tags` 删掉并集
补进的标签，并去掉 note 里的 `refreshed_candidate_key`、`added_tags` 与 `collected_genres`，
下一轮按那时的判据重来。

## 理由

- 收录一个词就是用户给出的判断，收录出的标签不进账本，等于这个判断只改了页面。
- ADR-0079 放行超集的理由是「人判过的标签一个不少，新增的只是补空」；不删之后，这条理由对
  「候选少了几个」同样成立。来源这一次没给某个标签，说明不了人当时判错了。
- 目录名兜底只收两种都要成立的证据：目录写着完整番号，文件名写着番号里那段足够长的数字。
  两位数字（`WX-17` 的 `17`）碰巧撞上的余地太大；不对目录名跑解析器，凑出来的番号就进不来。

## 被否决的方案

- **收录后整套重落。** 现值非空时非官方来源不能替换，这条路对它们走不通；走得通的那些
  还会按来源重写整套标签，把用户手删的标签加回来。
- **目录名也按文件名规则解析。** `[mtfdz.club]WX17.3` 这类合集名会被解析成一个像样的番号。
- **描述性称呼自动否决推广到所有番号。** 与 ADR-0079 决策三、ADR-0025 冲突：素人企划番号的
  真名常在别处查得到，交人仍有意义。这次不改范围，那几行按冲突逐条审核。

## 后果

- 来源不能覆盖非空现值，或组内身份未经确认时，仍交人复核。
- 撤回并集补标签之后，生词那一行不回复核页，下一轮按当时的收录结果重补；要让它停下，先改
  genre 的收录决定再撤。
