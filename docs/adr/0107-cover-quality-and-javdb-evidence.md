# ADR-0107：官方高清封面优先，JavDB 图片仅作复核证据

状态：Accepted

日期：2026-10-17

关联：ADR-0030、ADR-0032、ADR-0031。

## 背景

封面来源、分辨率与取景分别决定图库显示质量。社区图片可能带有站点水印；可信官方快照中的大图需要进入候选比较。整幅宣传大封与包含封底、书脊、正封的封套具有相近比例，不能只依靠比例决定裁切。

## 决策

- 可信官方快照与在线官方候选共用身份校验、解码和尺寸比较。远程封面的高清重探界限为长边 1600px；本地自备图与 FC2 商品图沿用各自的来源保护。同类官方图只按像素面积升级，官方图可以替换社区转存图。
- 缺少快照的有码作品复用已有 `DmmSource` 查询官方目录，DMM 成功证据与其目录镜像共用图片候选；FC2 快照只提取发行方存储原件。目录连接失败、拒绝访问与解析失败属于未取得，不能写成来源确认没有。
- JavDB 图片只作来源复核与图像一致性证据，不作为正式封面、下载兜底或页面显示兜底。安装、封面索引与详情投影均执行此边界。官方图片未取得时显示未取得状态。
- 有 JavDB 来源证据的历史封面及其边车移入 `review/` 下的可恢复归档，保留逐番号清单。来源未登记不等于 JavDB，不凭缺少来源批量移走文件。整个流程不写 ledger。
- `poster-crop-v13` 结合主脸是否跨越正封先验边界识别整幅大封，主脸在边界任一侧都受保护；梯度突出度与正封侧基线用于书脊切点。两条满高接缝夹出的居中正封，在两侧纹理均低于正封四分之一时优先保留中间区域。手工取景保持原样。
- `cover-face-v4` 在整图上挑主脸，再决定是否按正封过滤。没有可辨书脊的 4:3、√2:1 画布，以及左侧主脸面积至少为右侧两倍的无书脊图片，按整幅大封取景；可信书脊与居中正封保持传统封套布局。整幅大封容许明显占据主体的闭眼或侧脸，人脸缓存校验算法版本与图片尺寸，逐图核查支持 `--refresh-faces`。
- 整幅大封在竖版大图卡片按主脸居中填满，在横版小图卡片完整放入容器；两种视图均不使用模糊补边。图片比例不同，横版完整显示时允许实色留边。
- 传统正封完整居中显示，比例差异处保留卡片纯色底。卡片不使用封底作为模糊背景，避免封底颜色出现在已裁好的正封边缘。

## 验证与复核产物

来源筛选、拒收安装、只读封面路径、详情投影、批次归档与取景计算分别运行行为回归。桌面及 390×844 手机浏览器核对取景切换、无模糊背景和横版完整显示。

`scripts/audit_cover_artwork.py` 输出逐文件 CSV，`scripts/upgrade_audited_covers.py` 保存官方候选尺寸、来源和替换备份，`scripts/quarantine_javdb_covers.py` 保存归档清单；网络失败与确认未取得分别记录，不将低清放大视为高清。
