# ADR-0106：种子保留纠错历史，精确撤销自己的错误断言

- 状态：Accepted
- 日期：2026-10-17
- 修订：ADR-0075 的集合纠错与版本判据；ADR-0073 的事实分发边界继续成立
- 关系：ADR-0052 的来源归属与整批撤回；ADR-0040 的扫描结算后继

## 背景

用户要求在本地解决种子可能携带错误的问题，资料上传暂不实施。仓库种子停在 `2026-09-26.1`，本机后续纠错没有自动进入该文件。种子里没有头像、作品封面或取景结果。代码规则会随版本分发，文字资料需要显式导出。

仅发布更新的文字资料不足以修正接收端：别名、来源编号与链接以集合形式只增不减，曾被导入的错误会持续存在。同一来源时间戳下的资料更正也不能仅靠 `fetched_at` 判断。任务历史可清理，不能承担长期纠错记录。

## 决策

### 显式撤销

种子 v2 带累计撤销清单。每项有稳定标识、纠错原因、实体身份锚点、字段与精确旧值；撤销记录由可复核的纠错证据产生，不能根据包中缺席自动生成。每一版继承已有撤销，跳过中间版本也能执行纠错。

导入只撤销仍由 `auto:seed` 拥有且精确匹配的旧断言。用户手工复核、本机抓取与其他来源拥有的断言保留。身份命中多个实体、所有权不符或与本机事实冲突时记录复核明细；不自动改规范名、合并身份或删除实体。精确撤销先于正向补充，同次导入允许将错误来源编号替换为已复核编号。

### 校验与原子性

导入前校验格式、字段类型、身份锚点、包内正负断言冲突与内容校验值。无效包完整拒绝；运行时异常也须回滚本次事实与历史写入。校验通过说明包在结构和断言关系上可接受，不能证明每条来源事实都正确。LLM 输出、推测与未解决冲突仍是候选。

### 导入历史

`seed_pack_history` 独立记录版本、单调递增修订号、内容 SHA-256、累计撤销清单和导入时间，不随任务历史清理。相同版本更换内容、倒退修订号、丢弃已接受撤销记录均拒绝。同一份包可重复运行，为新增的本机实体补资料。升级 v2 后拒绝旧包回放。

后继幂等键绑定包内容，避免同名版本内容变化被历史成功任务静默跳过。种子拥有的资料可按已接受修订修正，不依赖抓取时间发生变化。

### 分发与权限

种子更新通过只读导出与差异复核，保存在仓库外（ADR-0111）。来源链接、编号和文字资料可进入包；图片与真实媒体不在范围内。导出不写真实账本。新迁移只建立种子导入历史表，真实环境应用仍按项目迁移授权、备份和核验流程执行。

国内个人成人内容创作者的资料只有在公开身份依据可核对、艺名与账号或平台档案的对应关系明确时才进入种子。只有本机 Stash 导入、文件名、转载称呼或未经复核的别名关系时，不纳入分发；来源置信度分数不能代替身份依据。发版复核保留可核对的来源与对应关系，未取得依据的条目留在本机。v2 导出过滤 Stash 来源别名与编号，没有其他可分发事实的实体不进入包。停止收录不等于证明旧断言错误，不据此删除本机资料或生成撤销。

## 验证

临时账本覆盖精确撤销、接收端手工资料保护、更正编号补入、相同抓取时间的资料纠错、重复与跳版本导入、旧包回放、历史撤销遗漏、损坏包拒绝及运行时回滚。真实资料的具体撤销另有复核产物；不能以这些机制测试代替事实核验。
