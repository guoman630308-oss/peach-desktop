# ADR-0108：本地 NFO 核查与覆盖复核

- 状态：Accepted
- 日期：2026-10-17
- 依据：用户要求先读取本地 NFO，扫描刮削时仍查询来源；补漏无需复核，覆盖已有值必须复核。

## 决策

NFO 是本地资料来源，存在文件不代表资料完整、正确或符合 Peach 字段格式。处理任务先读取并规范化本地字段，再按现有来源链核查在线资料。来源成功缓存与缺失缓存继续有效，过期后重新查询。

有效本地字段优先补空；NFO 缺失或无效的字段由在线来源按现有身份与规范化规则补全。XML 无法解析、根元素不支持或内容番号冲突时记录问题，整份 NFO 不作为该视频的字段证据；已能确认视频番号时继续在线查询。无效日期由现有日期规范化入口忽略。

NFO 核查中，与已有值相同的结果不占复核队列。不同值保留来源、原文快照及覆盖复核标记，官方来源和本地 NFO 均不能绕过复核直接覆盖。首次处理时，本地字段可补空，在线差异同时保留为待复核项。人工选择一个来源时记录该组已展示的候选身份；相同候选不重复要求判断，来源值改变则按现有候选过期机制重新复核。

该决定修订 ADR-0029 的“NFO 字段不收在线候选”，以及 ADR-0038 在 NFO 核查范围内的链首自动覆盖规则。不涉及没有本地 NFO 的既有来源政策，不改变作品身份校验、人工归属保护或真实账本写入授权。

## 验证

临时视频、NFO、来源桩与迁移生成的隔离账本覆盖完整资料、分卷共享、缺字段、无效日期、损坏 XML、异格式及番号冲突；核对自动补空、覆盖待复核、批准写入、缓存复用和真实 revision 冲突。真实反馈的 NFO 样本未取得。
