# ADR-0037：新导入补人物资料并规范 NFO 标签

- 状态：Accepted
- 日期：2026-09-20

## 背景

独立测试包新导入 `ABW-358` 后，NFO 已给出女优 `涼森れむ`，r18.dev 同一人物对象还给出
DMM id、假名、罗马字与 `image_url`。ADR-0029 规定 NFO 已给出的字段不再收在线候选，结果
人物真值虽然正确，附着在在线人物对象上的头像与别名也一起丢了。

同一份 NFO 的 tag 还有另一个问题：本地标签此前绕过 `genre_taxonomy` 原样落库，页面因此同时
出现繁体写法与发行属性，例如 `主觀視角`、`苗條`、`單體作品`、`フルハイビジョン(FHD)`。
前三类分别应当规范化、规范化和排除，只有词表不认识的自定义标签应保留原文。

## 决策

**一、NFO 标签经过同一套 genre 词表。** 已知内容词投影为 Peach 中文标签，明确的画质、促销、
发行属性和演员编成不落库；未收录词仍按 NFO 自定义标签原样保留，不进入「未知 genre」复核。

**二、NFO 人物真值与同名在线人物资料可以合并。** 在线人物规范化主名必须与 NFO 人物逐字相同，
只补 `external_id`、假名、罗马字、头像地址与资料来源，不替换 NFO 的演员列表。名字不一致时仍按
ADR-0029 丢弃在线演员候选。

**三、人物候选自动落库后立即补别名与头像。** 别名仅写到已经连着该资产的人物实体；与别的实体
规范名或别名冲突时不写。头像只接受 Peach 自己从 r18 combined 数据拼出的
`https://pics.dmm.co.jp/mono/actjpgs/<文件名>`，候选文件被改成任意地址也不会请求。

**四、125×125 的 DMM 图只作首次头像。** 它是来源人物 id 直接绑定的官方缩略图，身份可靠但清晰度
不高；缺头像时先消除首字母占位，之后仍可在换头像页用 Gfriends、社媒或本地图片替换。它不进入
高清头像批处理，也不降低那套批处理的尺寸与人脸门槛。

## 理由

- 人物主名精确相同且资料来自同一个发行记录，不需要再靠图片或模糊姓名猜身份。
- 自定义 NFO 标签是用户数据，不能因为词表不认识就删除；画质和促销词已有明确的非内容判据，
  不应继续污染内容筛选。
- 官方缩略图虽小，仍比无头像更有用；把它标成可替换的首次头像，不会妨碍后续质量升级。

## 被否决的方案

- **NFO 有演员就完全不看在线人物对象。** 这正是别名与头像缺失的原因。
- **自动选 Gfriends 同名结果的第一张。** 同名可能对应多人，`ななみ` 已有三人撞名样本；缺少
  身份绑定时自动挑图会装错人。
- **丢掉所有词表未收录的 NFO 标签。** 会删除用户自己的分类，与本地 NFO 的可信边界相冲突。
- **把 DMM 缩略图算作高清头像候选。** 125×125 达不到现有显示与批处理质量门槛。

## 后果

- 新导入在扫描与采集完成时即可得到可搜索的假名、罗马字别名和首次头像，不必打开复核页。
- 旧账本不会因升级自动重写；重新采集相关项目时才经过新规则。
- 处理状态新增别名、头像、冲突与失败计数；单张头像网络或解码失败不打断整批导入。
