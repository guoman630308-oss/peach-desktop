# ADR-0062：没有封面参照时，图库两家目录的两张照片互相作证

- 状态：Accepted
- 日期：2026-09-24
- 修订：ADR-0057 第三条（仍要封面）

## 背景

ADR-0056 与 0057 认人都要一张她单人作品封面上截到的脸作参照。没有参照就写「图库 N 张认不准」，
退到封面截脸；封面上也截不出脸时什么都不装。

不同目录的独立照片可以互证身份；同一照片的不同裁切不能当作独立证据。短单名命中多人时，还需要多数约束。

## 决策

**一、图库自证。** 一张参照都没有（没有单人封面、封面截不出脸、截出的脸提不出特征）时，
过尺寸门槛、提得出脸的候选两两比。照图库先后，第一张满足以下两条的装上：

- 另一个来源目录里有一张候选与它过线（`COSINE_THRESHOLD` 0.363）且低于 `NEAR_DUPLICATE`：
  两家各存的一张不同照片。同一目录的两张、同一张照片的两份，都不算。
- 和它过线的候选（含自己，近重复也算）在全部提得出脸的候选里过半。二十几个人的名下偶然
  有某一位的两张，二对二十几过不了；`星野千紗` 三张里 Warashi 与 Javrave 认得，二比三，装 Warashi。

**二、有参照照旧。** 有一张以上参照时仍按 ADR-0056、0057 判，图库自证不替代封面参照，
只在参照缺席时补位。参照有而全都对不上的，仍是「比不出她」，退到封面截脸。

**三、留证据。** 边车 `face_match` 里 `covers` 为空、`required` 记 0，`corroborated_by` 记作证那张与
两张之间的分数，另加 `agreeing`（认得的候选数，含自己）与 `faces`（提得出脸的候选数）。
活动页那一行的来源写「（按图库互证认定）」。

**四、判据版本。** `MATCH_RULE` 升到 3，进指纹。存量里缺图或装着封面截脸的女优按新判据各重比一次。

## 后果

- 两张以上不同照片彼此过线时可安装头像；只有两张而且是同一张照片的两份（余弦 ≥ 0.9）
  仍装不上，与 ADR-0057 第二条一致。
- 短单名命中一堆人的仍靠多数那一条挡；名字链里的短单名本来就不拿去检索（ADR-0055 第四条），
  图库那边按 `gfriends.candidates` 的名字链找，链上若有这种别名，多数那一条是最后一道。
- 装错的可能仍在：某家目录把别人的照片挂在她名下、另一家照抄，两张就会互证。头像选择器里
  一点就换，边车留着两张各是哪一目录哪一张。
- 片商资料页人像、抽帧作参照不在本 ADR 内。
