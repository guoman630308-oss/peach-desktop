# ADR-0104：头像图库独立互证

- 状态：Accepted
- 日期：2026-10-11
- 修订：ADR-0062 的图库互证适用范围

## 依据

`浅野こころ` 的 Moodyz 原图为 600×783，S1 原图为 564×720，均满足标准头像尺寸。两张照片与 `SNOS-301` 封面裁片的 SFace 余弦分别为 0.326、0.304，未达到 0.363；两张图库照片彼此为 0.4587，满足不同来源、不同照片的同人判据。自动封面裁片的身份未核实，不能作为否决独立图库证据的唯一依据。本机只读复现记录位于数据根 `review/asano-avatar-audit.json`。

## 决策

图库先按封面参照和三方互证认人；未取得匹配结果时，继续按图库自身的独立证据认人。图库互证必须来自两个不同目录、两张不同照片，余弦达到官方阈值且低于近重复阈值，并在全部可提取人脸的候选中占多数。尺寸门槛、来源顺序和人工选择保护保持成立，模型不可用时不产生独立互证结论。

图库独立互证的来源记录使用空 `covers` 与 `required=0`，同时通过 `unmatched_covers` 保存未匹配的封面编号、资产 ID 和每张图库候选的分数。它们不构成匹配证据。`MATCH_RULE=8` 纳入实体指纹，使自动封面兜底可按当前规则复核。已装着的人工头像保留。

## 影响面与验收

- 数据与契约：无 schema 或 ledger 真相字段修改；来源边车增加可选取证字段，公开 API 字段不变。
- 页面与视口：页面结构、换头像操作和响应式布局不变；后台选图共用头像安装入口。
- 反向状态：人工换图与候选历史保留，自动封面可被满足身份判据的图库人像替换。
- 回归：封面未匹配时的图库多数互证、档案小图、少数候选拒收、近重复拒收、模型不可用及人工头像保护。
- 复用：沿用 OpenCV SFace、`match_gallery` 与 `_gallery_agrees`；无新增依赖，不调整识别阈值。
