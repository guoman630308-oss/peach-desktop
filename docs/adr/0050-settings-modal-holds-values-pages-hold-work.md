# ADR-0050：设置弹层只放一行一个值，表单、长任务和危险操作放整页

- 状态：Accepted
- 日期：2026-09-24
- 关系：修订 [ADR-0047](0047-feed-subscriptions-enter-from-the-performer-page.md)「后果」里订阅源所在的位置，
  其余各条不变

## 背景

设置弹层和管理页各自长出了同一类东西。弹层的「这台电脑」一格挂着整张配置页，左栏拆成
「通用 / 媒体 / 网络与访问 / 更新与维护」四条；`/configuration` 又是同一个 island 的整页版，
遗留层为这一格写了双挂载和「页签里再拆页签」的特判。「更新与维护」里还有媒体修复：一轮几十分钟起步，
要确认、要轮询进度，而弹层一关轮询就停，进度也就看不到了。订阅源列表放在「通用」里，
和它管的东西（关注、新作）不在一处。视频缩略图采集那一行在弹层里自己轮询进度，
活动页上却看不到这个任务的中文名和计数。

用户定下的分工是：设置弹层管整个项目的偏好，管理页负责查看和管理数据。

## 决策

**一、设置弹层只放「一行一个值、改完就生效」的控件。** 开关、下拉、数值框，改完立刻保存，
没有「保存配置」按钮，也不轮询。

**二、下面三类一律放整页，不进弹层：**

- 带「保存配置」按钮的多字段表单；
- 需要轮询进度的长任务；
- 需要 `confirmModal` 确认的危险操作。

**三、按这条判据落位：**

- `/configuration` 是唯一的配置编辑页，进管理菜单；只对运行 Peach 的那台电脑列出，
  判据仍是 `/healthz` 的 `configurable`。弹层「这台电脑」只留一张摘要卡：媒体库数、端口、
  更新状态，外加「打开配置页」。别的设备上那一格是一句话，说明要去哪里改。
- 媒体修复挪到数据管理页，排在「扫描与采集」之后，和它同一种任务卡。
- 订阅源列表挪到关注管理页的「订阅源」页签（`/follow-manage?tab=feeds`），仍按 ADR-0047 不收地址。
- 视频缩略图采集的档位下拉留在弹层的「播放」里，状态行只写一句；进度在活动页（任务中心）看，
  任务有自己的中文名，计数按任务中心读的字段上报。
- 搜索记录条数存在服务端 `/api/settings`，所有访问端同一个数。账本里还没有这个值时，
  第一台打开的设备把本地改过的数同步上去一次。
- 「保持登录时间」不设控件。登录页的「保持登录」勾选框固定送 30 天，不勾只保持本次浏览器会话。

## 被否决的方案

**弹层和整页各挂一份配置页。** 同一份表单两个入口，遗留层要为弹层里那一份写页签拆分、
挂载去重和字形表，改一处布局要在两种外壳里各验一遍。

**媒体修复留在弹层，关弹层后在后台接着轮询。** 进度仍然只有打开弹层时才看得到；
而确认弹层叠在设置弹层上面，焦点和关闭顺序都得另做。

**「保持登录时间」改成只有 30 天一档的下拉。** 只有一个选项的控件没有东西可选。

## 后果

- 新增的设置项先过第二条判据：要「保存配置」、要轮询、要确认的，找它所属的整页放。
- 设置弹层左栏不再按配置页的分区拆条，「这台电脑」只是一条。
- 浏览器本地设置里的 `loginDays` 键在加载时删除，登录页也不读它。
- 管理菜单多一项「配置」，手机和别的电脑上不列。
