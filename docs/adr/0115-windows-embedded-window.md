# ADR-0115：Windows 内嵌窗口

- 状态：Accepted
- 日期：2026-10-23

## 决策

Windows 窗口测试包使用 pywebview 的 WebView2 后端，主线程运行窗口消息循环，原版托盘在同进程的独立线程运行。托盘继续持有服务、首次设置切换、健康检查、检查点和退出取证；打开首页与配置页通过可注入回调进入窗口。普通托盘入口的默认行为保持浏览器访问。

包通过 `native-window.txt` 标记选择窗口入口，CLI、安装辅助与监视器仍由统一构建入口分派。窗口测试版使用独立安装标识和默认资料目录。窗口控制复用 filelock 与原子文件，回环 UDP 指令带随机认证值，动作固定为打开、配置、隐藏与退出，不接受 URL 或代码。

WebView2 使用独立持久配置，不暴露领域 JavaScript API。顶层页面仅接受当前或已保存设置中的本机服务地址；外部 HTTP/HTTPS 链接交给系统浏览器。下载使用系统对话框，全屏使用 WebView2 原生事件。关闭窗口隐藏并暂停页面媒体，托盘退出结束窗口及自有服务。

窗口版只选择带 `PeachDesktop` 身份的更新包。未提供对应发行资产时使用专用安装包更新，不把普通发行包当作窗口版更新。

## 影响

原版网页、数据库结构、资料来源、人物关联和联网业务保持同一实现。Windows 需要 WebView2 Runtime，Python.NET 与 pywebview 作为锁定的可选依赖。浏览器扩展、用户脚本和外部站点登录仍通过原版浏览器与凭据流程使用。普通浏览器验证之外，交付需要真实 WebView2 的启动、设置、播放、全屏、重开与退出证据。
