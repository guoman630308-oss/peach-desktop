# ADR-0100：有码内容标签优先 JavDB

状态：采纳

日期：2026-10-10

## 背景

用户指出宽泛的 `アナル` 不能断言肛交，并要求优先采用准确的社区内容标签。JavDB 详情页的 `類別` 链接给出来源原词，可以与日英来源词共用 `genre_taxonomy`。已取得的 32 部样本与类别索引用于离线映射预览，实时全库来源取证和逐资产回填尚未执行。

## 决策

- `metadata-source-policy-v6` 仅对有码作品的内容标签排序：本地 NFO、JavDB、其余现行来源。JavDB 的身份仍是 community；标题、出演者、厂牌、系列、日期及其他作品类型沿用既有来源判据。
- `アナル`、`Anal`、`Anal Play`、`アナル責め`、`アナルシリーズ`、`肛門・肛交` 投到既有标签「屁眼」。明确表示肛交的词才投「肛交」。没有可靠语义的词保留为 UNMAPPED，已映射部分可按判据结算，未知部分继续复核。
- 用户确认的具体译名进入规范词表及筛选分组，职业、偏好、身体部位与行为分别表达。「风俗女郎」表达角色，「风俗店」表达场景；「恋腿」「恋乳」不推断外观，「扶她」表达幻想设定。中英文类别按同一链接核对，见 [来源词复核](../reference-snapshots/javdb-category-translations.md)。来源版本、发行、排名和兜底分类保留在原始快照，不据站点标签断言本地文件属性。
- 缺标签的有码作品在必填标量结算后单独补取 JavDB，不扩展其他社区查询。取页复用来源路由、缓存、缺失记忆、冷却与超时机制，已尝试来源不重复请求，失败保留已取得的标量。
- 已有标签的作品通过 `scrape_codes` 按番号重取候选；例行库处理保护已有字段。新 JavDB 候选允许重判旧的自动标签决定，使用真实番号核对身份，包含 `asset:<ID>:tags` 主键。
- 自动替换只撤下 `javinizer:*` 和 `auto:metadata-tags@*` 的标签归属，保留 `manual`、`name`、`stash` 与实体关系。人工 approved 继续按并集补新增；更高置信度的候选可以更新同名 `filename` 扁平投影，并保留实体的多来源证据。保留人工判断、候选身份及时间。落库记录 `metadata-censored-javdb-tags` 与 `tag_policy=censored-javdb`，不冒称官方来源。
- 回填真实馆藏须有同轮明确授权、逐资产预览、备份与正式账本写入入口。离线来源差异不能代替真实账本的来源归属审查。

## 验证与影响

临时库回归覆盖已有旧标签的重取、自动决定重判、人工并集、同名其他归属保护、未知原词与作品类型边界；源码实现与测试原子交付，最终集成测试由协调者统一执行。无 schema、请求端点或页面布局变化；复核候选的排序、内容与过滤采用本决策。

本决策是 ADR-0038 与 ADR-0082 对有码内容标签的有界例外，其他字段和类型的判据保留。
