# ADR-0085：组织与三个代码仓库

- 状态：已接受
- 日期：2026-09-30

## 背景

Peach 应用、官网和演示站具有不同的运行入口、依赖和发布目标。用户决定将三个项目分别公开源码，统一托管于 GitHub 组织 `peach-mitao`。

## 决策

| 仓库 | 范围 | 入口 |
| --- | --- | --- |
| `peach-mitao/peach` | 应用、前端源码、测试、发行与项目文档 | Peach 自托管服务 |
| `peach-mitao/peach-site` | 官网页面、交互、文字编辑预览与部署配置 | `peach.video` |
| `peach-mitao/peach-demo` | 演示 Worker、回放协议、演示交互与部署配置 | `demo.peach.video` |

应用仓库通过 GitHub 转移功能保留提交、标签、发行与问题记录。应用主分支保持 `master`，站点主分支使用 `main`。本机目录和生产入口保持现有布局。

网站代码与素材分开管理。演示录制数据、媒体、凭据、数据库、本地证据、缓存和构建输出不进入公开 Git 仓库；部署所需的素材与录制包在本地发布目录中提供。官网媒体清单只记录公开资源地址与内容哈希。

演示前端由应用仓库的 `web/` 构建产物同步；源码的真相仍在应用仓库。独立演示工程不复制整份应用源码。三个项目各自声明依赖、许可证范围、预览方式和发布验证入口。

## 影响

GitHub 仓库地址、下载入口、发行查询和发行脚本使用组织地址。GitHub 提供的旧地址重定向承接既有链接；历史 ADR 与尚未重新构建的客户端保留其原有引用。

组织资料页列出三个项目和官网、演示站、下载与反馈入口。组织成员和账单、双因素认证及第三方凭据不由分仓操作调整。
